# ⚽ Дворовый Кубок

Веб-приложение для компании друзей, которые собираются поиграть в футбол на выходных:
честно делит игроков на команды по уровню и проводит мини-турнир с табло, таймером и таблицей.

**Открыть:** https://ren4115.github.io/dvorovy-kubok/

## Возможности

1. **Игроки** — база друзей с рейтингом 1–10, отметкой «вратарь» и позицией; быстрая отметка «Сегодня играет».
2. **Команды** — деление на 2–6 команд или по размеру (5 на 5): вратари → «змейка» по рейтингу → улучшение перестановками.
   Индикатор баланса, «Перемешать», перетаскивание игроков, условия «вместе / раздельно», весёлые названия и цвета манишек.
3. **Турнир** — серия матчей, круговой турнир (+ финал), группы + плей-офф, режим «Вылет».
   Табло с +1/−1, таймер со свистком, авторы голов, пенальти в плей-офф, тай-брейки вплоть до жребия.
4. **Итоги** — чемпион дня с кубком и конфетти, награды, бомбардиры, картинка для чата, история и статистика за всё время.

## Технически

- Один файл `index.html` (HTML + CSS + JS), без сборки и зависимостей, кроме шрифтов Google Fonts.
- Без регистрации и сервера: данные хранятся в `localStorage` браузера.
- Mobile-first, тёмная тема по умолчанию и светлая «солнечная» тема.

Запуск локально: просто откройте `index.html` в браузере.
